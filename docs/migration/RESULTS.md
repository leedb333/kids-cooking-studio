첫 실행 실패의 원인과 조치:

1. 피자 PNG 생성 중 새 홈으로 이동하면 문서가 닫혀 저장이 취소됨 → 다운로드 요청이 끝난 뒤 홈 이동. 같은 시나리오로 재검사 통과.
2. 파일 보존 검사의 이동 변경 예외 목록 반영 필요 → 모델·이미지를 계속 전부 검사하고, 이동 관련 TSX 7개만 명시적으로 구분.
3. 새 저장 격리 검사 4개가 홈 이동 완료 전 저장값을 조회함 → 목적지 도착을 기다린 뒤 검사. 모두 통과.

홈의 피자 카드는 완성 기록을 자동 초기화하지 않고 그대로 연다. 기존 확인창으로 새로 만들 수 있도록 검사 시나리오를 맞췄다.

세부 결과: [LOCAL-CHECKS.json](LOCAL-CHECKS.json), [PNG-CHECKS.json](PNG-CHECKS.json). GitHub의 독립적인 전체 32개 검사 결과는 PR의 Checks를 확인한다. 아직 실행되지 않은 검사 결과를 이 문서에서 성공으로 간주하지 않는다.

실제 기기 설치·실제 사용자 진행 기록·배포 후 동일 출처 이어하기는 미검증이다. 신규 main 병합과 Pages 배포는 수행하지 않았다. 실기 확인 전 이전 완료로 선언하지 않는다.
